2. **SABER（一套评测大模型编程 Agent 操作安全性的基准）开始盯上真实项目风险。**  
SABER 这篇论文关注的是**大模型编程 Agent**（能自己读代码、改代码、执行任务的 AI 编程助手）在“有状态项目工作区”里的操作安全性 💡。所谓**有状态项目工作区**，可以理解成一个真实项目现场：里面有文件、配置、历史修改和上下文，不是干净的考试题。研究重点不是单纯看 AI 会不会写代码，而是评估它在真实项目里行动时会不会带来安全和操作风险。[论文页面(briefing)](https://huggingface.co/papers/2606.01317)

3. **Unsupervised Skill Discovery for Agentic Data Analysis（一项让数据分析 Agent 自动发现技能的研究）提出轻量增强思路。**  
这篇论文研究**数据分析 Agent**（能自动做表格分析、写分析步骤、生成结论的 AI 助手）如何在不重新训练模型的情况下变强 🚀。摘要提到的**inference-time skill augmentation**（推理阶段技能增强，指 AI 回答问题时临时注入可复用做事步骤）是一种更轻量的办法，不需要改动模型参数。论文还强调**unsupervised skill discovery**（无监督技能发现，让系统自己从任务中找出可复用方法），目标是为数据分析任务积累“操作经验”。[arxiv 论文(briefing)](https://arxiv.org/abs/2606.06416) [论文页面(briefing)](https://huggingface.co/papers/2606.06416)

4. **ForeSci（一套评估大模型 Agent 前瞻性科研判断的基准）瞄准 AI 科研眼光。**
